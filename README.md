# bookmarklets

A bookmarklet is a bookmark that does something instead of going somewhere — you click it and the page you are already on changes. This repository is where that collection lives: one entry per bookmarklet, each one short enough to read before you run it.

## Status

**The licence and this page are here; the bookmarklets have not been published to the repository yet.** When they land, each gets its own file, a one-line description of what it does to the page, and the `javascript:` line ready to copy.

## How to install one

1. Open Chrome's bookmark manager (`Ctrl+Shift+O`) and add a new bookmark.
2. Give it a name you will recognise.
3. Paste the bookmarklet's `javascript:…` line into the **URL** field.
4. Open the page you want it to act on, then click the bookmark.
